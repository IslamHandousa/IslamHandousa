Securing CI/CD pipelines and Kubernetes platforms for Saudi government entities. Currently at **Kafaat Digital Transformation (KDX)**, assigned to the **General Authority of Civil Aviation (GACA)**, running a GitLab-centered delivery model where nothing reaches production except through protected merge requests, pipeline security gates and approved change requests.

9+ years in software engineering, 3+ years in DevSecOps. A developer background in **.NET Core** and **Next.js** means vulnerabilities get fixed in code, not just reported.

---

## What I do

- **Shift-left security in pipelines** — SAST, DAST, SCA and container image scanning as mandatory gates in GitLab CI/CD and Azure DevOps.
- **Reusable, restricted pipeline templates** — teams consume shared pipelines without seeing or altering the security logic.
- **NGINX & Kubernetes hardening** against real audit findings — least-privilege RBAC, policy as code (Kyverno), runtime security (Falco).
- **GitOps change control** — every production change, from app fixes to NGINX routes, as a reviewed merge request deployed by pipeline. Zero manual changes on production servers.

## Impact at GACA

- **95% reduction in production downtime** by moving every change to reviewed merge requests and pipeline-driven, zero-downtime deployments.
- **~15 minute onboarding** for new applications onto restricted, reusable pipeline templates with security gates built in.
- **Six NGINX Plus audit findings closed with zero downtime** — outdated NGINX, clear-text HTTP, TLS 1.0/1.1, weak CSP, missing HSTS, version disclosure.

## Current focus

- Building an 8-VM production-style **DevSecOps reference lab**: Jenkins, SonarQube, Trivy, OWASP ZAP, Argo CD, HashiCorp Vault, Kyverno, Falco on a 3-node kubeadm cluster with Prometheus / Loki / Grafana and Velero backups.
- Preparing for **CKA, CKS, AZ-400, Red Hat EX280** — expected 12/2026.

## Selected projects

**NGINX Plus Ingress hardening on GKE** — government client, 2026
Closed all six findings of a vulnerability audit. Upgraded to NGINX Plus R37 LTS with zero downtime, migrated the controller from Deployment to DaemonSet, fixed a hostPort rollout deadlock. All shipped through GitLab merge requests and Azure DevOps pipelines.

**DevSecOps reference platform** — personal lab, 2026
8-VM production-style stack with Jenkins + Azure DevOps source, SonarQube, Trivy, OWASP ZAP, Argo CD, Vault, Kyverno, Falco on a 3-node kubeadm cluster. Documented runbooks for etcd backup, scoped RBAC and troubleshooting.

**Azure DevOps GitOps delivery architecture** — 2026
Template-and-consumer pipelines with GitOps deployment for .NET Core applications on Kubernetes.

**SNAP — Saudi National Air Navigation Plan** — GACA Vision 2030, 2023–2025
Full-stack and DevOps on GACA's airspace-modernization portal: .NET Core and Next.js on Azure, SQL Server, NGINX load balancing. Produced the solution and infrastructure design with per-layer security controls.

**Yalla Shipping** — freelance, 2023
Self-hosted GitLab on-premises with private Docker registry, so source and images never left the company network. GitLab CI/CD with SonarQube gates, Kubernetes behind NGINX, Grafana monitoring.
